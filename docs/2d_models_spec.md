## Goal

Produce 2D tracks from VGGT and D4RT behind `Tracker2D` (Q3), then build the shared Step 2 outputs: one figure with every method on the same sample (Q5) and the 2D metrics table (Q6).


## VGGT (Q3)

- Use VGGT's built-in tracking head (`track_head`, CoTracker2-style) with the query points of the query frame. Visibility is `vis * conf` above a threshold. Document both thresholds.
- VGGT takes the frames as a set of views with frame 0 as the reference. Put the query frame first, or run one pass per query frame and document the choice.
- **Memory:** VGGT-1B does not fit long DAVIS videos in 8 GB. Process windows of K frames with overlap, chain the windows through the last frame of the previous window, and report K. Use Colab for full-length runs if needed.
- **Coordinate with Paul:** `exp/vggt_non_rigid` already adds a VGGT `Tracker2D` (Step 1 adjustment 2). Reuse it instead of writing a second one.

## D4RT (Q3)

- D4RT answers a query `(u, v, t_src, t_tgt, t_cam)` with a 3D point. For 2D tracking, set `t_cam = t_tgt` and project the point into the target frame with the predicted intrinsics. This gives the 2D position, and the visibility comes from the model.
- Check first what Open-D4RT exposes (a 2D head or 3D only), and say in the report which one is used and why.
- Run Open-D4RT from its clone in `third_party/Open-d4rt`. Keep the wrapper thin, so the model is only imported when the tracker is used.

## CoTracker3

Already implemented (`src/tracking/cotracker.py`, AJ 62.6% on DAVIS). Only register it with the same settings as the other methods.

## Q5 and Q6

- **Q5:** one DAVIS sequence from the Step 1 non-rigid subset, the same 3–4 frames, and the 8 methods (6 baselines + VGGT + D4RT), plus GT.
- **Q6:** rows = methods; columns = AJ, <δ_avg, OA on the Step 1 subset (main table) and on full DAVIS (reference). Every value comes from `scripts/evaluate.py`.
