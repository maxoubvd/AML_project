# Branch `feat/3d-tracking`: 3D baselines, VGGT 3D and D4RT (Q8, Q9, Q10)

**Owner:** TBD (D4RT part: Mohammadreza) · **Base:** `main`, once `feat/2d-baselines`, `feat/2d-models` and `feat/depth-lifting` are merged · **Merge:** PR into `main`

## Goal

Build every Step 3 method behind `Tracker3D` and score them with `scripts/evaluate.py --task 3d` (official TAPVid-3D metrics, median scaling, raw predictions).

## Methods

| Method | Built from |
|---|---|
| LK + depth | `LKTracker` + `lift_tracks` |
| DINOv3 + depth | `DinoSimilarityTracker` + `lift_tracks` |
| DINOv3 + depth + constant velocity | DINOv3 matching with a **3D** constant-velocity model: predict in world coordinates (`cam_to_world`), project the prediction into frame t to centre the search window, then lift |
| LK + DINOv3 + depth | `LKDinoTracker` + `lift_tracks` |
| CoTracker3 + depth | `CoTracker3` + `lift_tracks` |
| **VGGT 3D** (Q7) | VGGT 2D tracks + VGGT depth/poses; second variant with Depth Anything |
| **D4RT** | native 3D output, converted to per-frame camera coordinates |

One generic wrapper covers most rows: `Lifted3D(tracker_2d, depth_estimator)` in `src/tracking/lifted.py`. Only the constant-velocity baseline and D4RT need their own class.

## Fairness

- All "+ depth" baselines use the **same** depth source (pick one, e.g. VGGT depth). Add a second set of rows only if time allows.
- The same TAPVid-3D subset (Step 1 part B) and the same query-first protocol for every row.

## Deliverables

```
src/tracking/lifted.py           # Lifted3D
src/tracking/dino_cv_3d.py       # 3D constant velocity
src/tracking/d4rt.py             # D4RTTracker3D (next to the 2D wrapper)
scripts/make_3d_table.py         # Q10 table from results/3d/*.csv
results/3d/table.csv             # Q10
results/3d/q9_<sequence>.png     # Q9: 3D trajectories, GT vs methods
```

## Definition of done

1. Every method runs with `python -m scripts.evaluate --task 3d --tracker <name>` on `configs/subsets/tapvid3d_test.txt`.
2. Q10 table (3D-AJ, APD_3D, OA), generated by a script.
3. Q9 figure on one sequence of the subset, the same for every method.
4. A paragraph per baseline for Q8 that states the depth source and how poses are used.
